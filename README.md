# ADB Quick Tool

一个轻量 Windows ADB GUI 小工具，用于多设备选择、内嵌终端、文件浏览、截图查看、应用管理和快捷执行。

## 功能

- 一键刷新 `adb devices -l`，刷新按钮 5 秒内重复点击只执行第一次
- 多设备列表选择
- 窗口最左侧 `40px` 图标栏提供刷新设备图标和设置图标，设置中配置 `adb`、`scrcpy`、`python`、截图目录、下载目录
- ADB 设备区固定高度为 `150px`，设备较多时在表格内纵向滚动；列表会先显示序列号、状态和型号，再后台补齐网络类型、以太网 IP、以太网 MAC、蓝牙 MAC、安卓系统版本
- 文件列表、应用列表与版本信息、截图、应用/文件操作、设备在线检测均在后台执行；ADB 响应较慢或设备暂时离线时不会阻塞主界面，较新的刷新请求会自动忽略旧结果
- 双击 ADB 设备默认打开 `scrcpy`，不额外弹出 CMD 窗口；scrcpy 窗口创建后默认按当前屏幕工作区高度铺满，高度确定后宽度按比例缩放，后续仍允许用户手动缩小放大；当设备通过 USB 直连，或 ADB 连接地址中的设备 IP 与本机任一启用网卡处于同一局域网子网且设备网络类型明确为有线时，会默认使用高画质参数启动，其他连接默认关闭高画质但可在设备右键菜单中启用
- 设备列表右键支持复制 `adb connect` 命令、复制 `adb shell` 命令、冻结/恢复、重启设备、安装应用、删除、禁用高画质/启用高画质、打开 `scrcpy`、新建 shell、打开系统设置、截图并查看、文件浏览器、应用列表；当右键点在“序列号/IP、型号、以太网 IP、以太网 MAC、蓝牙 MAC”单元格上时，会额外出现对应字段的复制菜单，并复制未截断原始值
- 主工作区高度为 `280px`，按左 3/5、右 2/5 分栏；左侧显示 shell，右侧显示设备管理标签页：文件浏览、应用列表、截图查看
- 固定 PC CMD 窗口，位于“输出”上方，使用常驻 `cmd.exe` 进程，支持直接在终端区输入、持续交互和会话内状态保留；执行 `adb connect` / `adb disconnect` 后会按“动作 + 目标”做 3 秒防抖并增量同步设备增删
- 左侧 `ADB Shell` 每个 tab 现在改为独立的 `cmd.exe /Q /C adb -s <serial> shell` 会话，复用 `PC CMD` 的 `adb shell` 行编辑/补全内核；Tab 内输入 `exit` 后会随 shell 进程结束自动关闭当前 tab
- `ADB Shell` 的命令与目录补全缓存未命中时会在后台加载；首次按 `Tab` 触发加载，缓存就绪后再次按 `Tab` 即可补全，不会因等待设备目录而卡住界面
- `PC CMD` 输出默认保持在底部；用户使用鼠标滚轮查看历史输出时，会保留滚轮控制的位置，点击、输入和聚焦不会额外改变滚动条
- `快捷执行 / PC CMD` 与 `PC CMD / 输出` 之间都支持拖动分隔条手动调整高度；窗口整体拉高时，默认由 `PC CMD` 优先增长，“输出”保持当前基线高度
- 终端内容区底部额外预留约 3 行可视余量，降低最后一行贴边或被遮挡的概率
- 快捷执行，支持 `cmd`、`shell`、`py`、`ps1`；同名前缀的 `开/关` 按钮会自动合并成一个内嵌开关控件，例如 `自动支付` + `开/关` + `[shell]`
- 设备文件浏览支持双击目录进入、右键双击返回上一级、双击文本文件编辑后上传、双击其他文件下载后用本机默认应用打开、右键菜单文件操作、新建文件/文件夹、拖拽上传、列排序和按列宽尾部省略显示
- 文件浏览器显示当前设备，默认路径 `/sdcard/`
- 应用列表显示当前设备，默认过滤用户应用，支持全部、用户应用、系统应用过滤；默认不显示底部横向滚动条；名称显示包名最后一段，冻结应用会在名称前显示 `*`，列内容按列宽尾部省略显示
- 应用列表右键支持安装应用、打开应用、重启应用、杀死应用、冻结应用/激活应用、清除数据、卸载、复制包名、查看属性；支持把本地 `APK` 文件拖到应用列表内容区直接安装到当前设备
- 截图查看支持截图文件尾部省略显示，以及复制、删除、重命名、复制绝对路径和属性菜单
- 快捷执行新增按钮时会先按命令/脚本后缀自动识别类型，再允许手动修改；命令输入栏支持“浏览”选择脚本或程序文件；`cmd / py / ps1` 会注入到底部 `PC CMD` 执行，其中 `py` 使用设置里的 `python` 路径，`shell` 会在左侧当前 ADB Shell tab 中执行；右键仍支持编辑/删除，开关组右键可分别编辑开命令和关命令；普通按钮和开关组里的 `开/关` 小按钮都可按住左键拖动调整顺序，开关组会整体移动
- 保留底部“输出”区域，用于查看工具执行日志和结果

## 构建

在 PowerShell 中执行：

```powershell
.\build.ps1
```

输出文件：

```text
bin\AdbQuickTool.exe
```

本项目使用 Windows 自带 .NET Framework C# 编译器，不依赖 .NET SDK。

## 使用

1. 启动 `bin\AdbQuickTool.exe`
2. 点击“设置”，确认或选择 `adb.exe`、`scrcpy.exe`
3. 点击“刷新设备”
4. 双击设备可直接打开 `scrcpy`
5. 右键设备可打开设备操作菜单
6. 左侧 shell 区域可新建设备 shell，右侧设备管理区域可查看文件、应用和截图

配置文件会保存在 exe 同目录：

```text
config.json
```

截图默认保存在：

```text
screenshots
```

下载和编辑临时文件默认保存在：

```text
downloads
```

## 当前边界

- 左侧 `ADB Shell` 使用每 tab 独立的 `cmd.exe /Q /C adb -s <serial> shell` 会话，输入 `exit` 后会因 shell 进程退出而自动关闭当前 tab；底部 `PC CMD` 仍使用持续交互式 `cmd.exe` 会话。两者都支持直接在终端区输入并保留会话内状态，但仍不等同完整 Windows Terminal/ConPTY，复杂 TUI、全屏交互程序和精细光标控制场景仍可能受限。
- `PC CMD` 在普通 `C:\...>` 提示符行会启用本地输入行编辑/历史/补全；当进入 `adb shell` 的 Android 提示符行时，会继续使用本地输入行编辑，支持左右移动光标、Backspace 删除光标前字符、Delete 删除光标后字符、上下键切换 shell 历史命令、Tab 补全设备命令目录中的命令和当前设备文件名；多候选时会按真实 shell 风格列出候选并保留当前输入，按 Enter 后再提交整行命令；其他交互程序仍会自动切到“按键直通”模式。
- 设备文件编辑按文本文件处理，不建议用它编辑二进制文件。
- ADB 原生命令稳定能拿到包名、APK 路径和版本号；应用名称如果无法从设备侧解析，会先显示包名。后续可通过配置 `aapt.exe` 增强 APK label 解析。
